# 実装方針

単一の Worker が HTTP、メール、キュー、定期処理を受け付けます。会話の判断に必要なデータを読み出し、純粋関数が次の状態を決め、D1 の batch で会話と出来事を書き込みます。メールの原文と添付は非公開の R2 に置きます。

操作は名前、スキーマ、権限、手続きの組で登録します。運営画面と外部のクライアントは同じ操作を呼びます。拡張は静的に登録し、核のテーブルへの書き込みは核の手続きを通します。
