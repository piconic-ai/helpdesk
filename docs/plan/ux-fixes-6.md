# 見て分かるようにする

運営画面は文字が中心で、どのプロダクトの話か、誰からの声か、どこから届いたかを、読まないと区別できません。読む前に見分けられる手がかりを、決まった場所に、決まった形で加えます。

置き場所は `docs/plan/ux-fixes-6.md` です。`docs/plan/ux-fixes-5.md` を済ませてから着手します。

## 色の決まりを改める

`DESIGN.md` は「色は状態にだけ使う」と定めています。これを次のように改め、`DESIGN.md` に書きます。

- **状態の色**(失敗、判断待ち、成功、内部メモ)は、これまでどおり、文字と淡い背景の組で使う。
- **見分けるための色**は、アイコンと小さな点の中にだけ使う。プロダクトのアイコン、相手と運営者のアイコン、ラベルの点が当たる。文字、背景、枠、ボタンには使わない。
- 見分けるための色は、決めた8色の中から選ぶ。8色は、状態の色(赤、黄、緑)と紛れない色にし、白い地の上で形が見分けられる濃さにする。
- 色だけで区別しない。アイコンには必ず名前を添えるか、ツールチップと読み上げ用の名前を付ける。

## 1. プロダクトのアイコン

プロダクトごとにアイコンを持たせ、プロダクトの名前が出る場所すべてに添えます。

設定:

- 「設定」→「プロダクトと窓口」で、プロダクトごとにアイコンを設定する。
- 設定の方法は3つ。画像をアップロードする。絵文字を1つ選ぶ。何も設定しなければ、名前の頭文字と、8色から自動で決まる色の組になる。
- 画像は、運営者のアイコンと同じ検証と保存の仕組みを使う。角の丸い正方形で表示する(人のアイコンは丸、プロダクトのアイコンは角丸の四角、と形で区別する)。

出す場所:

- サイドバーのプロダクトの切り替え(選択中のものと、候補の一覧)
- 受信箱の行。いまのプロダクト名のチップを、アイコンと名前に置き換える。幅が狭いときは、名前を省いてアイコンだけにする
- 会話の見出しの属性の行
- 課題、声の集計、対応状況の集計、ヘルプ記事の一覧
- 設定と、拡張の設定の中の、プロダクトごとの区切り
- 公開の画面(ヘルプページ、チャット、フォーム、フィードバック)の見出し。ここでは大きめに出す
- ブラウザのタブのアイコン。公開の画面では、そのプロダクトのアイコンにする

大きさは、一覧で 16px、見出しで 20px、公開の画面で 28px とし、`DESIGN.md` に定めます。

## 2. そのほかの手がかり

| 対象 | 加えるもの | 出す場所 |
|---|---|---|
| 相手(ユーザー) | 名前の頭文字と、アドレスから決まる色の丸いアイコン。外部のサービスから顔写真を取得しない | 受信箱の行の左端、会話のメッセージ、課題の詳細の声の一覧 |
| 未読 | 行の左端の小さな点。開いたら消える。運営者ごとに持つ | 受信箱、フィードバック |
| 届いた経路 | メール、フォーム、チャットのアイコン | 受信箱の行の2行目、会話の見出し |
| 長く待たせている | 24時間を超えたら、待ち時間の前に印を付ける。72時間を超えたら、印を強くする | 受信箱の行 |
| ラベル | 色の点。ラベルごとに8色から選ぶ。チップの地は灰色のまま | ラベルが出る場所すべて |
| 状態 | 文字に、形の違うアイコンを添える(未対応、返信待ち、完了、迷惑メール、受付済み、確認済み) | 状態のバッジ、絞り込みの候補、サイドバー |
| 送信の状態 | 下書き、承認待ち、送信待ち、送信済み、失敗のアイコン | メッセージの見出し、受信箱の行 |
| 書いた主体 | 人、エージェント、拡張、システムで、アイコンの形を変える。人は丸い顔のアイコン、エージェントと拡張は固有の記号 | メッセージ、操作履歴 |
| 添付 | 種類ごとのアイコン(画像、PDF、表、圧縮、そのほか)と、大きさ | メッセージの添付の一覧 |
| 拡張 | 拡張ごとのアイコン。拡張の定義に持たせる | サイドバー、拡張の管理、会話の関連情報 |
| 課題 | 開いている・直した・知らせる待ちのアイコン | 課題の一覧、会話の関連情報 |
| 数値の動き | 過去の推移を示す小さな折れ線。色は使わず、濃淡で描く | 対応状況の集計のカード、声の集計の行 |
| 件数の比 | 行の背後の薄い横棒で、件数の大小を示す | 声の集計のラベル別・プロダクト別 |
| 空の状態 | 内容に合う線画のアイコンを1つ | 空の一覧、空の検索結果 |
| タブ | 未対応の件数を、タブの題の先頭に出す | 運営画面のすべてのページ |

## 3. 揃える決まり

- アイコンは1つの系統に揃える。線の太さ 1.5px、大きさ 16px を基本にし、色は文字と同じにする。BarefootJS で使っているアイコンの系統があれば、それに合わせる。
- 同じ意味には、どの画面でも同じアイコンを使う。対応の一覧を `DESIGN.md` に載せる。
- アイコンだけで意味を伝える場所は、ツールチップと読み上げ用の名前を必ず持つ。
- 1行に並ぶアイコンは5つまで。それを超える手がかりは、開いた先で示す。
- 受信箱の行は、手がかりが増える。左から「選択、未読の点、相手のアイコン、差出人と件名、プロダクト」、2行目に「番号、経路、最後のメッセージ、印、ラベル」、右端に「待ち時間、担当者」の順に固定する。

## 自動で確かめること

- プロダクトのアイコン: 3つの設定方法のそれぞれで、出す場所すべてに反映されること。未設定でも、頭文字のアイコンが出ること。
- 頭文字のアイコンの色が、同じ名前やアドレスに対して常に同じになること。
- 見分けるための色が、8色以外に無いこと。状態の色と同じ値が無いこと。
- アイコンだけの要素が、読み上げ用の名前を持つこと。
- 未読の点が、開くと消え、運営者ごとに独立していること。
- 受信箱の行が、3つの幅で、長い差出人・長い件名・多いラベルの例でも崩れないこと。
- 見た目の回帰のスクリーンショットを更新する。
