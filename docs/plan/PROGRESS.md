|---|---|---|

| 2 | 拡張の口・3拡張・HTTP API・CLI・MCP | 未着手 |

- [x] F01-AC1 登録した窓口アドレスに届いたメールが、そのプロダクトの会話として一覧に出る。
- [x] F01-AC2 新しい会話に、重複しない問い合わせ番号が付く。同時に届いた2通にも、別の番号が付く。
- [x] F01-AC3 2つのプロダクトの窓口に届いたメールは、それぞれのプロダクトの会話になる。
- [x] F01-AC4 同じ相手が返信したメールは、`In-Reply-To` または `References` によって同じ会話に入る。
- [x] F01-AC5 返信ヘッダーが欠けていても、件名の `[#123]` と差出人が一致すれば同じ会話に入る。
- [x] F01-AC6 別の差出人が、他人の会話の `Message-ID` や番号を使って送ったメールは、新しい会話になる。
- [x] F01-AC7 登録のない宛先へのメールは、会話にならない。
- [x] F01-AC8 同じメールが2回配送されても、メッセージは1件しかできない。
- [x] F01-AC9 解析に失敗したメールも、原文は R2 に残り、運営者が失敗に気づける。
- [x] F01-AC10 ISO-2022-JP と Shift_JIS のメールの件名と本文が、文字化けせずに表示される。
- [x] F01-AC11 Access で認証されていない要求は、運営画面のどのページも見られない。
- [x] F01-AC12 一覧は既定で「未対応」だけを表示し、状態・プロダクト・担当者・ラベルで絞り込める。
- [x] F01-AC13 件名・差出人・本文で検索できる。
- [x] F01-AC14 会話の画面から、同じ相手の過去の会話をたどれる。
- [x] F01-AC15 HTML メールの中の script は実行されず、外部の画像は読み込まれない。
- [x] F01-AC16 添付は、ダウンロードとしてだけ取得できる。
- [x] F01-AC17 返信すると、相手に届くメールの差出人は、その会話の窓口アドレスになる。
- [x] F01-AC18 返信は、元のメールへの返信として並ぶヘッダー(`In-Reply-To`、`References`)と、件名の `[#123]` を持つ。
- [x] F01-AC19 返信すると、会話は「返信待ち」になる。
- [x] F01-AC20 送信に失敗した返信は「失敗」と表示され、再送できる。
- [x] F01-AC21 送信の処理が2回走っても、相手に届くメールは1通である。
- [x] F01-AC22 内部メモは、どの操作をしても相手に送られない。
- [x] F01-AC23 相手から返事が来ると、「返信待ち」と「完了」の会話は「未対応」に戻る。
- [x] F01-AC24 完了にした会話は、既定の一覧から消える。
- [x] F01-AC25 会話に担当者を付けられ、担当者で絞り込める。
- [x] F01-AC26 迷惑メールにした会話は、相手から返事が来ても「未対応」に戻らない。
- [x] F01-AC27 自動応答とバウンスは、会話を「未対応」に戻さない。バウンスは、対応する返信を「失敗」にする。
- [x] F01-AC28 管理者は、プロダクトと窓口アドレスを登録できる。担当者は登録できない。
- [x] F01-AC29 相手を指定して削除すると、その相手の会話、メッセージ、原文、添付が消える。
- [x] F01-AC30 保存期間を設定すると、期間を過ぎた完了済みの会話の本文と添付が消える。設定しなければ消えない。
- [x] F01-AC31 会話の開始、受信、返信の送信と失敗、状態の変更、担当者の変更が、時刻と操作した人と一緒に `events` に残る。
