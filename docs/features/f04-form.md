# F04 プロダクトのフォームから問い合わせる

## 利用場面

利用者がプロダクトを開いたまま、開発者に質問を届けます。

## 得られる結果

フォームに受付番号が返り、運営者はそのプロダクトの受信箱からメールで返事を送れます。

## 体験の流れ

利用者が名前、返信先、件名と内容を入力します。プロダクトのフォームが送信し、受け取った番号を表示します。

## 作る範囲

公開キー、許可する Origin、1分あたりの回数制限をプロダクト単位で確認します。Turnstile を設定した窓口ではトークンも検証します。

## 作らないこと

会話履歴を公開するポータルは対象外です。

## 受け入れ条件

- **F04-AC1** 許可した Origin と公開キーから届いた質問が、そのプロダクトの新しい会話になり、受付番号が返る。
- **F04-AC2** 誤った公開キー、未許可の Origin、回数超過、または設定した Turnstile の検証失敗では、会話が作られない。
- **F04-AC3** フォームの返答には他の会話や運営者の情報が含まれない。

## 未決事項

実際のプロダクトに表示するフォームの文言とデザインは、その運営者が決めます。
