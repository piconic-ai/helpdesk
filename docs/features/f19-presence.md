# F19 同じ会話にいる運営者を確認する

## 利用場面

複数の運営者が同時に一件を開いている。

## 得られる結果

同じ会話を開いている他の運営者が表示され、返信欄への入力中はその状態が伝わる。

## 体験の流れ

会話を開き、返信欄に入力し、他の運営者の画面で状態を見る。

## 作る範囲

同じ会話にいる運営者を確認する操作と、その結果の表示。

## 作らないこと

編集ロック、返信の本文の共有。

## 受け入れ条件

- **F19-AC1** 同じ会話を開いている他の運営者が表示され、返信欄への入力中はその状態が伝わる。
- **F19-AC2** 更新が止まった運営者の表示は一定時間後に消える。
- **F19-AC3** 他の運営者が入力中でも返信を送信できる。

## 未決事項

なし。
