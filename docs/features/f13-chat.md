# F13 質問を記事または問い合わせにつなぐ

## 利用場面

利用者が自分の質問に合う記事を探している。

## 得られる結果

一致する記事があればリンクで案内され、解決できない場合は質問が問い合わせとして届く。

## 体験の流れ

質問を送信すると、Workers AI が公開記事との関連度を判定する。閾値以上の記事があれば案内し、それ以外は問い合わせ番号を返す。

## 作る範囲

公開記事の選択、設定可能な閾値、問い合わせへの引き継ぎ。

## 作らないこと

回答文の生成、ライブチャット。

## 受け入れ条件

- **F13-AC1** 閾値以上の関連度を持つ公開記事だけを案内し、会話は作られない。
- **F13-AC2** 一致する記事がない場合は元の質問と連絡先を引き継ぎ、問い合わせ番号を返す。

## 未決事項

日本語の質問に対する関連度の閾値は導入先の記事で確認する。
