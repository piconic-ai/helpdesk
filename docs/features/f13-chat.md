# F13 質問を記事または問い合わせにつなぐ

## 利用場面

利用者が自分の質問に合う記事を探している。

## 得られる結果

一致する記事があればリンクで案内され、解決できない場合は質問が問い合わせとして届く。

## 体験の流れ

質問を送信すると、Workers AI が公開記事との関連度を判定する。しきい値を超える記事があれば案内し、質問に合う記事がないときは連絡先を入力して担当者に送れる。

## 作る範囲

公開記事の選択、設定可能な閾値、問い合わせへの引き継ぎ。

## 作らないこと

回答文の生成、ライブチャット。

## 受け入れ条件

- **F13-AC1** 製品ごとのしきい値を超えた公開記事を上位3件まで案内し、会話は作られない。
- **F13-AC2** 一致する記事がない場合は元の質問を引き継ぎ、利用者が連絡先を入力して送ると受付番号と返信の目安を表示する。
- **F13-AC3** 登録した製品サイトでは、キーボードでチャットを開き、記事の本文を読み、元のやりとりへ戻れる。
- **F13-AC4** 「解決した」は解決の記録を残す。「解決しなかった」から送信した場合、運営者は受信箱でやりとりと元ページのオリジン・パスを確認できる。

## 未決事項

日本語の質問に対する関連度の閾値は導入先の記事で確認する。
