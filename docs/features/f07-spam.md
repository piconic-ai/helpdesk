# F07 迷惑メールの隔離

## 利用場面

運営者が自動振り分けされた問い合わせを確認する。

## 得られる結果

隔離されたメールには自動の受付返信が届かない。

## 体験の流れ

迷惑メールの一覧を開いて内容を確認し、必要なら未対応に戻す。

## 作る範囲

迷惑メールの隔離の設定、実行、結果の記録。

## 作らないこと

複数の組織にまたがるデータの集計・配送。

## 受け入れ条件

- **F07-AC1** 認証に失敗したメールと窓口自身を名乗るメールが迷惑メールの一覧に入る。
- **F07-AC2** 運営者が隔離を解除すると、受信箱に戻る。

## 未決事項

実サービスとの疎通と文面の評価は導入時に確認する。
