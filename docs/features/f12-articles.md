# F12 ヘルプ記事を管理する

## 利用場面

運営者がよくある質問への回答を公開して、返信でも案内したい。

## 得られる結果

利用者はプロジェクト別に公開記事を検索して内容を読める。

## 体験の流れ

運営者が Markdown を保存し、公開に切り替える。利用者は記事を探し、参考になったかを回答する。

## 作る範囲

記事の編集、公開・下書き、検索、返信案への追加、記事化候補と役立ち度の記録。

## 作らないこと

記事の版管理、承認ワークフロー。

## 受け入れ条件

- **F12-AC1** 指定プロジェクトの公開記事だけを一覧・検索・個別表示できる。
- **F12-AC2** 記事の Markdown は書式を保ち、安全な HTML として表示される。
- **F12-AC3** 公開記事のリンクを同じプロジェクトの会話の返信案に添えられる。
- **F12-AC4** 会話から記事化の候補を記録し、運営者が設定画面で確認できる。
- **F12-AC5** 利用者が役立ち度に回答すると記事と回答が出来事に記録される。

## 未決事項

なし。
