# F20 自分のアカウントで運営を始める

## 利用場面

作者以外の開発者が、初めて helpdesk を自分の Cloudflare アカウントに導入する。

## 得られる結果

運営者が必要なリソースと料金を確認し、窓口を登録して、問い合わせを扱う準備を整えられる。

## 体験の流れ

ローカルで手順を試し、設定を診断して不足を解消し、自分のドメインと Access に接続する。必要なときはデータを書き出して持ち出す。

## 作る範囲

英語・日本語の README、セルフホストと更新の手順、設定の検証、拡張開発の実例、ローカルで再現するスクリプト。

## 作らないこと

本番アカウントの作成、DNS の変更、本番への自動デプロイ。

## 受け入れ条件

- **F20-AC1** 空のローカル環境で、手順のコマンドを順に実行して初回設定から問い合わせの処理まで完了する。
- **F20-AC2** 必須 binding の不足時に、名前と直し方を示す。
- **F20-AC3** 手順のコマンドと設定名が、実際のスクリプトと設定に一致することを自動で検査する。
- **F20-AC4** doctor で窓口の未登録と送信ドメインの未設定を判別し、対処方法を確認できる。

## 未決事項

本番の DNS、Access、メールの到達性、運用費、および初めての運営者が文書だけで導入を完了できるかは、導入先で確認する。
