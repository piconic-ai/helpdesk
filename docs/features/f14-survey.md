# F14 解決の確認

## 利用場面

問い合わせを完了した相手に解決したかを確認する。

## 得られる結果

相手の回答が会話の出来事に残り、初回解決率の集計に使われる。

## 体験の流れ

完了通知の専用リンクから回答画面を開き、解決したかを選ぶ。

## 作る範囲

解決の確認の設定、実行、結果の記録。

## 作らないこと

複数の組織にまたがるデータの集計・配送。

## 受け入れ条件

- **F14-AC1** 完了後は解決したかを尋ねる自動メールが一度だけ送信される。
- **F14-AC2** 専用リンクからの回答を同じ会話の出来事に一度だけ記録する。

## 未決事項

実サービスとの疎通と文面の評価は導入時に確認する。
