# F05 定型返信を選んで下書きを作る

## 利用場面

運営者が何度も受け取る質問に、登録済みの文面を使って回答します。

## 得られる結果

相手の名前とプロダクト名が入った下書きを確認し、運営者が送信を承認できます。

## 体験の流れ

運営者が会話の定型返信を選びます。差し込み済みの文面が承認待ちで保存されます。

## 作る範囲

設定に定型文を登録し、名前とプロダクト名を差し込みます。メールの差出人に名前がない場合は、その返信先アドレスを使います。

## 作らないこと

入力内容を判定して定型文を自動送信する機能は対象外です。

## 受け入れ条件

- **F05-AC1** 会話に定型返信を適用すると、相手の名前とプロダクト名が入った下書きができ、運営者が承認するまで送信されない。

## 未決事項

登録する文面はプロダクトの運営者が決めます。
