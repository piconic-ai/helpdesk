# F16 会話の対応を一時保留する

## 利用場面

運営者が、次に対応する日時を決める。

## 得られる結果

指定時刻までは受信箱から消える。

## 体験の流れ

会話を開き、再表示する時刻を指定する。

## 作る範囲

会話の対応を一時保留する操作と、その結果の表示。

## 作らないこと

顧客に保留の通知を送る機能。

## 受け入れ条件

- **F16-AC1** 指定時刻までは受信箱から消える。
- **F16-AC2** 指定時刻になると、同じ番号の会話が受信箱に戻る。
- **F16-AC3** 保留を解除すると、受信箱にすぐに戻る。

## 未決事項

なし。
