# F18 新しい会話を振り分ける

## 利用場面

運営者が、製品や件名に応じて担当者とラベルを決めている。

## 得られる結果

条件をすべて満たした会話に設定した担当者とラベルが付く。

## 体験の流れ

管理者が設定に規則を登録し、新しい会話を受け付ける。

## 作る範囲

新しい会話を振り分ける操作と、その結果の表示。

## 作らないこと

自動返信、任意のコードの実行。

## 受け入れ条件

- **F18-AC1** 条件をすべて満たした会話に設定した担当者とラベルが付く。
- **F18-AC2** 一致しない規則は適用されず、規則の実行によって送信待ちは増えない。

## 未決事項

なし。
