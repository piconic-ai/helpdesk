# F10 解決と運営作業の指標

## 利用場面

運営者がプロジェクトごとの対応を振り返る。

## 得られる結果

対象期間に解決した件の所要時間、初回解決率、1件当たりの作業時間を確認できる。

## 体験の流れ

指標画面でプロジェクトと対象期間を指定する。

## 作る範囲

対象期間の開始時刻を含み、終了時刻を含まない。会話は最後の完了時刻、記事は「役に立った」と回答した時刻で集計する。

- A は、受付から完了までの時間と、記事を開いてから肯定回答までの時間を合わせた平均。
- D の分母は完了した会話。再開や否定回答がなく、運営者による返信が1回以下の会話を初回解決と推定する。
- F は、完了した会話のうち作業時間を計測できたものを対象とする。同じ運営者が画面を開いてから返信を確定するまでを合計し、1件当たりの平均を計算する。

時間の単位はミリ秒。対象が0件の指標は `null` を返す。

## 作らないこと

複数の組織にまたがるデータの集計・配送。

## 受け入れ条件

- **F10-AC1** 会話の完了と記事での解決から解決までの平均時間 A を計算する。
- **F10-AC2** 再オープン・返信回数・アンケートの結果から一度で解決した割合 D を計算する。
- **F10-AC3** 画面で会話を開いてから返信を確定するまでの時間から F を計算し、機械クライアントによる作業は含めない。

## 未決事項
