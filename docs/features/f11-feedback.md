# F11 フィードバックを受け取る

## 利用場面

利用者が返事を求めずにプロジェクトへ意見を送りたい。

## 得られる結果

運営者は問い合わせと区別して確認できる。

## 体験の流れ

利用者が送信し、受付番号を受け取る。運営者が確認済みにするか問い合わせに変換する。

## 作る範囲

フィードバックの受付、確認、問い合わせへの変換。

## 作らないこと

受付時の個別返信。

## 受け入れ条件

- **F11-AC1** 受付後は received の会話となり、番号が返る。
- **F11-AC2** 確認すると担当者の識別子と reviewed が残る。
- **F11-AC3** 問い合わせに変えるまで返信できず、変換後は同じ番号の未対応の問い合わせとして扱える。

## 未決事項

なし。
