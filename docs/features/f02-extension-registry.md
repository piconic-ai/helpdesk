# F02 拡張を設定して使う

## 利用場面

管理者が必要な拡張を選び、運営者が会話に合わせた操作を使う。

## 得られる結果

拡張の失敗は運営画面に記録される。設定から外した機能は操作の一覧から消える。

## 体験の流れ

管理者が設定と権限を確認し、有効な拡張が会話に操作を追加する。

## 作る範囲

静的登録、設定の検証、操作・画面・受付の追加、出来事の配送。

## 作らないこと

実行中の外部コードのダウンロード。

## 受け入れ条件

- **F02-AC1** 無効な拡張は画面・HTTP API・CLI・MCP から消え、受付は404を返す。
- **F02-AC2** 不正な設定は起動時に誤った項目と理由を示す。
- **F02-AC3** 出口の失敗後も会話は保存され、運営者は失敗を確認でき、配送は再試行される。
- **F02-AC4** 登録した操作を画面・API・CLI・MCP が同じ定義から呼び出せる。
- **F02-AC5** 拡張の実行環境は宣言していない権限の使用を拒否する。
- **F02-AC6** 核から同梱拡張への import を層の検査が検出する。

## 未決事項
