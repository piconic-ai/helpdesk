# F15 会話と出来事を書き出す

## 利用場面

運営者がプロダクトへの問い合わせを他の環境で分析する。

## 得られる結果

会話、メッセージと出来事を、レコードごとに独立して読める JSON Lines で取得できる。

## 体験の流れ

運営者が拡張を有効にし、API、CLI または MCP から書き出しを呼ぶ。

## 作る範囲

全プロダクトの履歴と個人情報のマスキング。

## 作らないこと

生の MIME やバイナリ添付の転送。

## 受け入れ条件

- **F15-AC1** 書き出しに全会話と出来事が含まれ、各行を JSON として解析できる。
- **F15-AC2** 既定の書き出しには、相手の名前とアドレスが自由記述や出来事に含まれる場合も残らない。
- **F15-AC3** CLI と MCP の操作一覧から同じ書き出しを取得できる。

## 未決事項

実際のデータ量に応じた分割方法は運用計測後に判断する。
