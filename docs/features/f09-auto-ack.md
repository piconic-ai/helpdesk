# F09 受付返信

## 利用場面

問い合わせを送った相手が受付結果を確認する。

## 得られる結果

自動送信と明記したメールに問い合わせ番号が載る。

## 体験の流れ

運営者が送信方針を承認し、新しい問い合わせを受信する。

## 作る範囲

受付返信の設定、実行、結果の記録。

管理者の有効化は全プロダクトに適用する。送信文面はプロダクト別にプレビューして保存できる。自動送信を示す定型文は日本語と英語を選べる。既存の文面は変更するまで従来の言語で送る。

## 作らないこと

複数の組織にまたがるデータの集計・配送。

## 受け入れ条件

- **F09-AC1** 新しい問い合わせの最初のメールにだけ番号を含む自動返信を送る。
- **F09-AC2** 自動送信・バウンス・隔離されたメールは返信されない。
- **F09-AC3** 自動返信には方針と有効化した運営者が記録され、未対応の会話は未対応のまま残る。

## 未決事項

実サービスとの疎通と文面の評価は導入時に確認する。
