# F17 同じ相手の会話をまとめる

## 利用場面

同じ相手が同じ窓口に、別件名で同じ問い合わせを送った。

## 得られる結果

統合後、一覧には統合先が残り、以前のメッセージも統合先で読める。

## 体験の流れ

運営者が元の会話を開き、統合先の会話番号を選ぶ。

## 作る範囲

同じ相手の会話をまとめる操作と、その結果の表示。

## 作らないこと

別の相手の個人情報を含む会話の間での統合。

## 受け入れ条件

- **F17-AC1** 統合後、一覧には統合先が残り、以前のメッセージも統合先で読める。
- **F17-AC2** 元の番号や元の Message-ID への返信は、統合先に届く。
- **F17-AC3** 相手または窓口が違う会話の統合と、循環する統合を拒否する。

## 未決事項

なし。
