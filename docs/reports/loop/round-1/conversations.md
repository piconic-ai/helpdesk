# 会話と受信箱の目視記録

同じ状態を 375 / 1024 / 1440 px の順で開きました。各状態で、作業の入口と結果、相手・対象・状態の判別、幅による省略・折り返し・操作の位置を確認しました。表に記した一部の 375 px 画像は操作位置までスクロールした画面です。「部品」と記した画像は周囲を含まない切り出しです。
