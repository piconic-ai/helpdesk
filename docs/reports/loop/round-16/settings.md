# 設定・拡張・操作メニューの画像レビュー

113状態を375・1024・1440pxの順に横並びで視認しました。339枚の一覧でも、フォーム・表列・操作面の位置と幅を比較しました。原画像の表示範囲は375×812、1024×900、1440×900です。画面名の一部は操作中の状態を表します。各節は実際に写っている作業を基準に記載しました。

## 先に扱いたい点

**信頼性に関する確認候補**　同じ番号・件名の会話 #4 で、赤い失敗表示が「送信失敗」と「別の返信で送信失敗」に分かれます。表示中の返信と別の返信への処置では、再送の判断が変わります。複数の画像で本文抜粋や承認待ちの件数も異なるため、画像のみでは不具合の判定はできません。同一の返信履歴を固定し、表示中の抜粋がどの返信かと、失敗した返信がどれかを照合する必要があります。上記以外に、作業不能または誤送信を静止画から断定した箇所はありません。

**静止画で確認できた優先事項**　1024pxではナビの移動先名が途中で切れます。375pxでは会話ラベルを新規作成するメニュー末尾が画面外に出ます。また、複数会話の担当割り当てで、一部だけに割り当て済みの印を説明する文が見当たりません。これらは現在の作業対象や次の操作を読み取る負荷になります。

## 確認範囲

画像で判断できるのは、撮影時点で表示されている文字、項目、配置、色、選択印と画面内の境界までです。Tab・矢印・Escape、フォーカス復帰、スクロールでの到達、透明部分を含む44pxのタッチ領域、動作速度、ダイアログ前後の位置、エラー時の入力保持、保存・送信・取消の結果、実際の権限管理は実操作が必要です。個別の質問への回答は画像の表示に限っています。
