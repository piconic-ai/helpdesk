# 独立視覚レビュー原記録

対象は public/ に含まれる107状態・321枚です。製品利用者向けの画面に加え、運営・設定・コンポーネント見本も含まれます。各状態を左から375、1024、1440pxの順に並べ、全状態を比較しました。指摘箇所は必要に応じて元画像を拡大せずに照合しました。判定は DESIGN.md と criteria.md に従いました。静止画から確認できるのは表示された結果です。応答時間、キーボード操作、実際の配送、クリック可能領域、画面外へのスクロール可否は検証対象外です。

## 指摘

|識別子・重さ|対象と幅|実際|期待|
|---|---|---|---|
|P01 中|behavior-sort-menu、menu-home-choice-menu-3。375、1024、1440、特に375|#11の長い差出人が375で4行、1024で3行、1440でも2行に折れ、本文を含めると行高がほかの会話より大きい。375ではラベル「再…」も識別しにくい。|一覧に必要な差出人・件名・抜粋を2段に収め、長い差出人の全文は詳細で読めるようにする。省略するラベルは件数にまとめる。|

対象画像で作業が止まる高の指摘はありませんでした。記事不一致、質問送信失敗、問い合わせ受付の各状態で、次の行動または結果を示す文言を確認しました。起票確認・既存課題への投稿確認には、リンクがこの端末で開く旨の表示があります。ローカルで収録された画面から、本番環境のリンク先は判定していません。
