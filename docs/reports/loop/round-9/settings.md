# 設定・拡張・関連メニューの画像レビュー

113状態の各1440・1024・375px、合計339枚を対象とした。各行の識別子は画像のファイル名から幅と拡張子を除いたもの。比較図の1行は左から1440・1024・375px。画像の表示高を揃えて全行を目視し、文言、開いた起点、選択印、対象と確定に関わる箇所は原寸でも確認した。以下の記録は画像に写った時点のもの。押下後の処理、非表示領域の操作、キーボード復帰、遷移中の位置変化は静止画からは判定できない。

## 所見

|番号|重さ・幅|実際|期待|
|---|---|---|---|
|M1|中・3幅|振り分けルールでラベル未指定のボタンは「すべてのラベル」。開くと「付けない」にチェックがあり、閉じてから読むと設定効果が逆になる。|閉じたボタンに選択中と同じ「付けない」を表示する。|
|M2|中・3幅|新規窓口の登録で「現在有効な拡張の自動送信ポリシーが承認されます」とだけ案内する。対象の拡張、どの条件で何が送られるかはこの画面で特定できない。|登録と一緒に引き受ける承認範囲を製品管理者が確定前に照合できるよう、対象と送信条件を示す。|
|M3|中・3幅|会話のスヌーズは再表示日時の欄に「年-月-日 時:分」、下に固定書式の例がある。日付や時刻を選ぶ入口は写っていない。|保存する日本時間を確認しながら、日付・時刻の選択で保留を指定できる操作を見せる。|
|M4|中・3幅|Slideを選んだ製品切り替えと通常のアカウントメニューは、開いた起点に背景・枠などの押下状態が見えない。キーボード状態の同じ部品には薄青の背景と縁がある。|入力方法にかかわらず、開いている間は起点に押下状態を残し、現在候補のチェックおよびフォーカス枠と区別する。|
|L1|低・3幅|プロフィールでアイコン画像を選ぶ部分だけ「Choose File」「No file chosen」と英語で表示される。|日本語で利用しているときは操作と未選択状態を他のフォームと同じ言語で読めるようにする。|

高に該当する中断・誤送信・確認時の位置ずれはこの画像群から特定できなかった。送信前の課題の公開先、ラベル削除の名前・件数、統合元と統合先はそれぞれ確認に使える位置にある。モーダルを開いた後の背景のスクロール位置だけで、開いた瞬間にページが移動したとは判定していない。
