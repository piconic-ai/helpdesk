# 第3周　運営画面・公開ヘルプの目視レビュー

この周に撮影した58状態・174枚について、375px、1024px、1440pxを個別に確認した。各状態で主操作と対象の対応、見出しとグループ、ボタン間隔、本文と値の折り返し、色と文字で示す状態、前後の作業への入口を調べた。とくに短い選択欄の現在値、ダイアログの確認文、入力エラーの後に残る値を原寸で見た。

| 重さ | 対象と観察 | 影響・期待する状態 |
| --- | --- | --- |
| 中 | 375pxの「対応状況の集計」で日付範囲を開くと、背後の製品と期間が「すべてのプロダ」「日付を指」で切れる。 | 現在の集計条件を読み切れない。製品選択を独立した行に置き、期間・日付操作を次の行に並べる。 |
| 低 | 記事候補からの執筆で「元の会話」と「記事の内容」のカードの縁が接する。 | 見出しと内部余白で参照と編集は区別できるが、カード間にも一覧と同じ間隔があると区切りが揃う。 |
