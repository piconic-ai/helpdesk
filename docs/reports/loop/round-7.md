## 指摘から直したこと

- **承認と送信。** 承認待ち一覧に未承認の下書きの本文を表示した。通常の会話一覧では相手の文と区別できるよう、抜粋の出所を示した。下書きの破棄では会話番号と対象本文を確認する。
- **内部メモ。** 保存通知の撮影で、実際のメモを保存する。以前は通知を表すURLだけを開いていたため、メモが履歴に存在しなかった。メモの入力面には保存後と同じ背景色を使う。
- **課題の公開確認。** 公開する要約と会話リンクを別に表示した。ローカルの確認画面ではリンクがこの端末向けと分かる。本番設定でループバックアドレスや HTTP の公開先を使うと、投稿前にエラーになる。
- **選択とメニュー。** 選択範囲は件名まで着色し、空の添付件数が「0」と出る表示を修正した。定型文を開いたボタンのそばにメニューを置き、差し込み後の本文を示す。ラベルは複数会話でも付け外しを続けられるようにし、名前変更時も行の位置を維持する。
- **関連情報と集計。** リンクに関連する課題名・会話件名を表示し、記事候補を作る画面でも元の会話を確認できる。集計は主要指標、改善と自己解決、件数の順に配置し、1024pxでも定義を読める幅を確保した。
- **公開窓口と設定。** 問い合わせを送る直前に入力内容を修正する入口を設けた。フィードバックの返信方針を送信前に知らせる。保存期間は「無期限」「日数を指定」から選ぶ。窓口アドレスの入力エラーには修正方法を示す。
