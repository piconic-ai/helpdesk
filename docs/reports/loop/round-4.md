# 第4周　集計と受信箱の検索を同じ幅で比較

375・1024・1440pxの163状態を撮り直した。集計の長い製品名と期間が読めることを確かめた一方で、375pxの承認待ちとフィードバック一覧に、検索欄の幅が半分になり「件名・差出人・本文を検索」の末尾が切れる症状が出た。集計用のレイアウトが受信箱の絞り込みメニュー内の製品選択にも適用されたことが原因だった。

一覧の検索欄を独立した行に戻し、集計ではフォーム直下の製品選択を手掛かりにレイアウトを適用した。承認待ちとフィードバックの両方について、375pxで検索欄の幅と絞り込みボタンの位置を調べるブラウザーテストを追加した。集計の長い製品・日付の検査も継続する。
