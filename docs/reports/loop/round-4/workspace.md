# 第4周　運営画面・公開ヘルプの目視レビュー

運営者の設定、公開ヘルプ、操作中のパネル・確認・通知を含む58状態を、この周で撮り直した375px・1024px・1440pxの174枚で調べた。各状態で、目的に合う主操作、対象・結果を示す文、文字切れ・余白、選択・エラー・空の状態、元の作業へ戻る入口を確認した。下表には実際の画像ごとの観察を記す。
