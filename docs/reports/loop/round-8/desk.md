# 受信箱・会話画面の独立視覚レビュー

対象は114状態、各375・1024・1440pxの計342画像です。全画像を同じ高さにした比較表と6状態ずつの拡大表で、各行を左から375、1024、1440の順に照合しました。重なり、文字、フォーカス、ダイアログの位置は代表画像を原寸でも照合しました。画像ファイルの共有識別子は下の見出しに記載しています。データ・送信の実挙動や反応速度は静止画から判定できません。

### 確認前後の位置

375pxのthread-approvalとapproval-confirmでは、背景のヘッダー罫線がy46→35、下書きカード上辺がy521→510で、どちらも11px上に移っています。1440pxでは罫線とカードは同じ位置にあります。375pxの承認前画像では起点ボタンの下部が画面外で、クリック前のスクロール量が特定できません。ボタンが見えている同一の位置で開いた瞬間に動く場合は、基準の「高」に該当します。現時点では原因と重さを未確定とします。

### 112　`thread-inbound`

### 113　`thread-note`

運営担当者が内部の引き継ぎを受信文と区別して読むために開きます。

3. 相手に届く？ 送られませんと明記。

観察　受信と内部メモを別カードに分割／黄色に内部メモの文字／入力欄はその後。

### 114　`thread-replied`

運営担当者が過去の返信を確かめて二重回答を防ぐために開きます。

1. 状態は？ 返信待ち。
2. 内容は？ 招待メールを再送した旨。
3. 送信者は？ 佐藤優、送信済み。

観察　顧客と運営者は異なる色丸／返信は淡灰カード／375でも配送状態は人物名の横。
