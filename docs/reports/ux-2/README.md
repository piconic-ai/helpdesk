## ブラウザで歩いた場面

| 場面 | 確かめた流れ |
| --- | --- |
| J1・J2・J3 | RFCメール受信 → 会話の発見 → 担当とラベル → 宛先付きプレビュー → 返信 → 次の問い合わせ。新着による再開、返信して完了、失敗理由を読んで再送まで操作した。 |
| J4 | 承認待ちの件数・行の印から下書きを開き、本文を編集。相手を確認して承認し、別の案は破棄した。送信済みになった本文を照合した。 |
| J5・J6・J12 | 記事を書いて公開し、返信に添付。チャットで記事を読んで戻り、別の質問と、記事で解決しなかった元の質問の両方から問い合わせを作成した。番号と運営の一覧の質問が一致した。 |
| J7・J9 | 公開のフィードバックを2件送り、確認済みへの変更と、問い合わせへの変換・返信を行った。新しく作った製品のフォームからの受信も確認した。 |
| J8・既存 Issue | 起票先と投稿内容を確認し、閉じられた Issue の通知案を承認した。既存 Issue も題名で選び、会話へのリンクをコメントする内容を確認して紐づけた。相手側サービスが受け取った本文を照合した。 |
| J10・J11 | 集計の製品・期間を変えて前期差を確認。削除する連絡先を選び、会話数を確認してキャンセルと実行の両方を試した。 |
| J13・J14・J15 | 複数会話を担当・分類・完了にして戻した。自分の表示名・画像を変更し、担当者候補と会話の記録を照合。キーボードだけで返信の確認・送信から次の未対応へ進んだ。 |
| 補足 | スヌーズの設定・解除・取り消し、定型文の挿入、同一窓口の会話の統合、ルールでの担当・通知・隔離を確認。運営者が発行したトークンで CLI の一覧取得と MCP の下書き作成を行った。375px でも、画面遷移と返信・完了をキーボードのみで操作した。 |

## 歩いて見つけた問題

- モバイルの多数ラベルで残りの数が2行に折れた。件数と単位を同じ行に固定し、切れたラベルは全文を読めるようにした。
- 幅1440pxで保存日数欄が926px、集計の日付欄が726pxまで伸びていた。短い入力はそれぞれ81px・166pxになり、説明文は680px以内に収まることをブラウザで測定した。
- 記事候補が Esc・外側クリックで閉じず、閉じたあと返信欄に戻りにくかった。ブラウザ標準のポップオーバーに変更し、キーボードで元のボタンに戻れることを確かめた。
- モバイルのメニュー内でキーボードヘルプを開くと戻り先を失った。先にメニューを閉じて次のダイアログを開き、終了時にトリガーへフォーカスを戻す。背後のクリックが届かないことも実際に試した。
- 画面を開き直した返信欄の値がプレビューに反映されないケース、複数管理者の編集を古い取り消しが壊すケースを確認し、それぞれ復元した本文と保存版を使うようにした。
- 停止中のフォームに記事から進める箇所を修正した。フォームの無効時や Turnstile 設定が足りないときも、登録済みのメール窓口へ進める。期限切れの記事評価は選択を保持してやり直せる。

## 判断と検証の範囲

- 人物の写真は PNG/JPEG、2 MiB・200万画素以内とした。写真以外・大きすぎる画像・拡張子を偽ったファイルが拒否されること、別オリジンからのプロフィール変更が拒否されることを検証した。
- 新しい埋め込み先はチャットを表示できるサイトとして扱う。JSON API の送信元要件と、構成で設定した Turnstile は維持する。認証できない送信元には受け取った本文を表示せず、正規フォームと窓口を案内する。
- ファイルと認証情報はブラウザの下書き保存から除いた。秘密の値を画像記録に含めていない。外部へすでに送ったメール・コメントと、確定したデータ削除は取り消せないため、実行直前に確認する。
- D1・R2・Queues・Worker と Chromium はローカルで動かした。メール配送、GitHub、Webhook、AI はテスト用の外部サービスを使った。実在の受信トレイへの到着、実アカウントの GitHub や Access は本番での確認事項として残る。

## 再現方法

`pnpm build` の後、`pnpm test:ui` で回帰画像と描画値、`pnpm test:ux` で操作を検査する。画像を意図して更新するときは `HELPDESK_DAILY_CAPTURE=docs/reports/ux-2/after pnpm test:ui`、通しの記録は `HELPDESK_UX_REPORT=1 HELPDESK_UX_STEPS=docs/reports/ux-2/steps pnpm test:ux` を実行する。両方の収録後、`node tests/ui/daily-report.mjs` で比較ページを生成する。修正前の画像は `65112f2` のコードとデータで収録した。
