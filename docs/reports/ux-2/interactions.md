# 操作の置き方

| 画面 | 操作 | 置き方と結果 |
| --- | --- | --- |
| 共通 | プロダクト、受信箱、承認待ち、フィードバック、記事、集計、設定、トークン、アカウントを開く | 画面。選択内容は URL に残る。 |
| 共通 | モバイルのナビを開く、閉じる | ダイアログ。選んだ画面へ移動する。 |
| 共通 | キーボード操作を見る、閉じる | ダイアログ。ヘルプボタンまたは ?、Esc で元の操作へ。 |
| 受信箱 | 状態・プロダクト・担当者・ラベルで絞る、文字検索、条件を解除 | ポップオーバーまたは選択欄で条件を選び、結果の画面へ移動する。 |
| 受信箱 | 待たせている順・新しい順、前後のページ、会話を開く・戻る | 画面。並び・ページ・条件を URL で復元する。j / k で行を移動し、Enter で開く。 |
| 受信箱 | 複数行を選ぶ、選択を解除 | その場。選択した件数を一括操作バーに表示。 |
| 受信箱 | 自分が担当する、完了にする、まとめて完了・迷惑メールにする | その場。単独では a / e も使える。結果から元に戻せる。 |
| 受信箱 | 選んだ会話に担当者・ラベルをまとめて付ける | ポップオーバー。結果から前の状態を復元する。 |
| 会話 | 完了、再開、未対応に戻す、迷惑メールにする・解除する | その場。副次操作は「その他の操作」。 |
| 会話 | 自分が担当する、ラベルを外す | その場。見出しと記録に変更を表示。 |
| 会話 | 担当者を選ぶ・外す、ラベルを選ぶ・作成して付ける | 見出しのポップオーバー。 |
| 会話 | 相手の過去の会話、拡張の情報、関連 Issue、閲覧者、操作履歴 | 横のパネル。リンクから会話・Issue を開く。状態・担当者・ラベル・振り分けは時系列にも表示。 |
| 会話 | 受信箱に戻る、次の未対応へ | 画面。u でも一覧へ戻れる。 |
| 返信欄 | 返信と内部メモの切り替え、入力、プレビューを開く・閉じる | その場。r / n で入力欄へ移る。会話別に入力を保持。 |
| 返信欄 | 関連記事を探して添える | ポップオーバー。選んだ題名と公開 URL が本文に入る。 |
| 返信欄 | 返信を送信、送信して完了、承認して送信、再送 | ダイアログ。宛先を示して確認する。Cmd / Ctrl + Enter も同じ確認を通る。 |
| 会話 | 内部メモを保存、承認前の下書きを編集 | その場。メモは会話内に残る。 |
| 会話 | 下書きを破棄する | ダイアログ。対象1件を削除する。 |
| 会話 | メールの HTML を読む、添付をダウンロード | メッセージ内の隔離表示、またはファイルリンク。 |
| 会話 | 保留日時・定型文を選ぶ、記事候補を書く | ポップオーバー。保留解除はその場で実行する。 |
| 会話 | フィードバックを確認済みにする・戻す | その場。問い合わせに変えるときはダイアログで確認。 |
| 会話 | 統合先を件名で選ぶ、統合する | ポップオーバーで選び、ダイアログで統合先を確認して移動。 |
| 会話 | Issue の要約を書く、起票する | ポップオーバーから確認ダイアログへ。リポジトリと実際に公開する内容を示す。 |
| 会話 | 既存の Issue を探して紐づける、紐づいた Issue の影響を確認する | 一覧画面で題名を選び、ダイアログでリンク先と投稿内容を確認。会話の横のパネルから関連を開く。影響調査は結果画面。 |
| 集計 | 対象プロダクト、7・30・90日・指定期間を選んで集計する | 画面。定義、直前の同期間との差、少数時の案内を数値と並べる。 |
| 記事 | 一覧、候補を参照、作成、編集、下書き保存、プレビュー | 画面。記事ごとの URL を持ち、本文とプレビューを照合。 |
| 記事 | 記事を公開、公開記事を読む | 公開はダイアログ、公開後は顧客が読む画面を開く。 |
| アカウント | 表示名・画像を設定 | 画面。保存後の表示をアカウントと会話で確かめる。 |
| 設定 | プロダクト・窓口を登録、送信者名・個人名の表示を変更 | 画面。プロダクト単位で保存。 |
| 設定 | 運営者の名前・権限、本文の保存期間を変更 | 画面。変更対象と保存結果を表示。 |
| 設定 | 連絡先のデータを削除 | 相手を選んでダイアログへ。宛先と会話数を確認し、キャンセルまたは削除。 |
| トークン | 名前・権限を選んで発行、失効 | 発行は画面。失効はトークン名を示すダイアログ。 |
| 拡張 | 用途別に探す、有効にする、設定を開く | 有効化はその場、設定は画面。接続に必要な設定の有無を確認できる。 |
| 拡張 | 無効にする | ダイアログ。対象の拡張名と停止する操作を確認。 |
| 拡張設定 | 製品の受付を開始、公開先・埋め込み用コードを確認、埋め込み先の登録・解除、返信目安を保存 | 画面。製品別の設定を操作し、公開画面で結果を見る。 |
| 拡張設定 | 定型返信の作成・編集、Issue のリポジトリ登録 | 画面。日常の会話では登録済みの候補を選ぶ。 |
| 拡張設定 | 振り分けルールの作成・編集・順序変更・削除 | 画面。順序変更はその場、削除はダイアログ。 |
| 拡張設定 | データを書き出す、個人情報を含めるか選ぶ | 画面。出力の範囲を選び、結果を表示。 |
| 公開ヘルプ | プロダクトを選ぶ、検索、記事を読む | 画面。該当記事がなければ同じ製品の問い合わせ先へ進む。 |
| 記事 | 役に立った・立たなかったを回答、問い合わせる | 回答はその場から結果へ。記事と否定回答の両方に問い合わせへのリンク。 |
| チャット | 質問、記事を開く、解決しなかったので問い合わせる | 画面。質問を引き継ぎ、連絡先を指定して受付番号を得る。 |
| 公開フォーム | 問い合わせ・フィードバックを送る、入力を修正して再送する | 画面。受領後に番号と返信の扱いを表示。 |
| アンケート | 解決したか回答する | 画面。回答の受付結果を示す。 |
| エラー・空の一覧 | 受信箱・公開ヘルプへ戻る、条件を解除する | 画面。利用者と現在の場所に応じた移動先を示す。 |
