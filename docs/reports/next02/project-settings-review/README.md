# 拡張の設定とプロジェクトのメンバー

30件のプロジェクトがあるデモを Chromium で開いて確認した。画面幅は 375、800、1280 px。各画像は画面内の対象を切り出したもの。

| 確認した画面 | 修正前 | 修正後 |
| --- | --- | --- |
| 拡張の管理 → GitHub Issue | [28大会のリポジトリを列挙](issue-before.png) | [デモ起動時](issue-initial.png)。Slide と Desk は設定済み。2027年の大会で GitHub Issue を有効にすると、[不足1件と「起票先を設定」](issue-missing-target.png)が出る。 |
| 拡張の管理 → 詳細 | | [GitHub Issue の詳細](issue-details.png)。起票の操作、公開する内容、返信の承認、設定、権限を確認できる。 |
| 開発者カンファレンス 2027 → メンバー | [氏名が3行、メールアドレスが14行](member-before.png) | [氏名とメールアドレスが各1行](member-after.png)。役割と、最後の管理者の変更条件は続けて読める。 |

メンバーの行の高さは、画面幅 375 px では 438 px から 150 px、800 px と 1280 px では 438 px から 132 px になった。3つの幅すべてで、起票先を設定する画面、一覧に戻る操作、氏名・メールアドレスの行数を [Playwright の回帰テスト](../../../../tests/ui/project-readability.pw.mjs) で検証する。
